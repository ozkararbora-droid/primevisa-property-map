# PrimeVisa Yunanistan Emlak Haritası

GitHub Pages için hazır paket. `index.html` uygulamadır; `data.json` güncel PrimeVisa Property Master verisidir. Uygulama her açılışta `data.json` dosyasını `no-store` ile yeniden yükler. Bu nedenle düzenli senkronizasyonda yalnızca `data.json` güncellenir.

Filtreler: bölge/proje/adres, fiyat, durum, firma, toplam m², yatak odası, Golden Visa ve en geç teslim. Atina merkeze ve denize uzaklık filtreleri kaldırılmıştır.
